# Gabi · Especialista em Noivas · landing page

Página única (HTML + CSS + JS, sem build) para Gabi, maquiagem e penteado para noivas em São Paulo e destination weddings. Objetivo: levar a noiva a consultar a data pelo WhatsApp.

## Como ver
Abra `index.html` no navegador ou, na pasta, rode `npx serve .`.

## Como mexer
- Textos, estilos e scripts estão todos no `index.html`.
- WhatsApp: constante `WHATSAPP_NUMERO`, no fim do arquivo (vale para todos os botões).
- Fotos em `fotos/`, vídeo do topo em `video/hero.mp4`.

## Prévia pública
As fotos, o vídeo e os depoimentos estão aqui só para a cliente ver o site funcionando. A página está marcada como `noindex` (buscadores não indexam).
